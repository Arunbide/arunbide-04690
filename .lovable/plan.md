# Portfolio visual redesign

## Outcome
Restyle the existing portfolio to match the uploaded product-led reference direction while preserving all current copy, project facts, links, and section order.

## Work
- Replace the dark editorial treatment with a clean light canvas, deep ink typography, restrained green accents, delicate linework, and soft product surfaces, while preserving the theme toggle.
- Recompose the hero around bold editorial typography and a prominent, responsive showcase built from existing real app screenshots.
- Carry the same visual language through navigation, project case studies, expertise, experience, process, contact, and footer; refine interactions and mobile layouts without changing content.
- Validate the desktop and mobile previews, navigation, theme toggle, and case-study links.

## Technical details
Use the existing React components, motion libraries, and semantic design tokens; avoid embedding uploaded reference posters as portfolio content because they contain illustrative, non-project UI text.
